**VLESS Checker** — это мощная и элегантная утилита для автоматического сбора, проверки и сортировки VPN-конфигураций протокола VLESS. Скрипт не просто проверяет доступность узлов, он делает это максимально быстро и предоставляет результаты в виде эстетичного консольного интерфейса и современного веб-дашборда.

---

 ✨ Ключевые возможности

* ⚡ **Сверхбыстрая асинхронная проверка:** Благодаря `asyncio` скрипт тестирует десятки ключей параллельно (до 50 одновременных подключений), экономя ваше время.
* 🎯 **Высокая точность пинга:** В скрипте отключен алгоритм Нейгла (Nagle's algorithm) на уровне TCP-сокетов, что позволяет замерять задержку с максимальной точностью до миллисекунд.
* 🌍 **Умная гео-сортировка:** Программа умеет парсить названия стран из ключей и аккуратно группирует рабочие серверы по локациям (Германия, Финляндия, Швеция и др.).
* 🎨 **Премиальный UI в терминале:** Анимированный стартовый экран, красивые индикаторы прогресса (progress bars) и итоговые таблицы в терминале, реализованные на базе библиотеки `rich`.
* 🌐 **Интерактивный HTML-дашборд:** По итогам проверки автоматически генерируется стильный HTML-файл с результатами. Он сохраняется прямо на ваш Рабочий стол. Дашборд включает цветовую индикацию качества соединения и кнопки быстрого копирования ключа в буфер обмена.
* 🔄 **Продвинутая агрегация:** Автоматически собирает сотни ключей из списка проверенных открытых GitHub-репозиториев[cite: 1].

 🛠 Установка и запуск

Для работы скрипта требуется установленный **Python 3.8** или выше.

**1. Клонируйте репозиторий:**
```bash
git clone [https://github.com/ВашЛогин/VPNchecker.git](https://github.com/ВашЛогин/VPNchecker.git)
cd VPNchecker
2. Установите необходимые зависимости:
Проекту требуются библиотеки requests и rich[cite: 1].

Bash
pip install requests rich
3. Запустите чекер:

Bash
python main.py
(Замените main.py на фактическое имя вашего файла, если оно отличается).

💻 Как это работает?
Сбор: Скрипт скачивает raw-файлы со списками vless-ссылок. Убирает дубликаты.

Анализ: Асинхронно стучится по TCP к хостам, замеряя отклик[cite: 1].

Фильтрация: Отбрасывает нерабочие ключи и те, чей пинг превышает 2000 мс[cite: 1].

Вывод: Показывает Топ-15 лучших локаций прямо в консоли с удобным выводом лучших ключей для быстрого копирования[cite: 1].

Экспорт: Создает файл working_keys.html на вашем Рабочем столе[cite: 1]. Просто откройте его в любом браузере!
