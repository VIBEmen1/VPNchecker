**VLESS Checker PRO** — это высокопроизводительная асинхронная утилита на Python для комплексного тестирования сетевых соединений, замера точной TCP-латентности удаленных узлов и автоматической генерации интерактивных веб-дашбордов. Проект демонстрирует продвинутые паттерны параллельного программирования (`asyncio`), работу с сетевыми сокетами на уровне ядра и проектирование консольных интерфейсов.

---

## ✨ Ключевые возможности

* 🎛 **Интерактивное меню:** Выбор из нескольких режимов работы (глубокая проверка всех стран, проверка конкретной локации, быстрый режим, фильтрация только самых быстрых ключей < 300 мс).
* ⚡ **Сверхбыстрая асинхронная проверка:** Скрипт тестирует десятки ключей параллельно (до 50 одновременных подключений) с использованием `asyncio`.
* 🎯 **Прецизионный замер пинга:** Отключение алгоритма Нейгла (`TCP_NODELAY`) на уровне сокетов исключает искусственные задержки стека TCP для миллисекундной точности.
* 📋 **Автоматический буфер обмена:** После завершения проверки скрипт автоматически копирует самый быстрый ключ в буфер обмена для моментальной вставки в ваш VPN-клиент.
* 📊 **Продвинутая статистика:** Подсчет среднего пинга для каждой локации и визуальная группировка по качеству соединения (🟢 Идеально, 🟡 Нормально, 🔴 Медленно)[cite: 2].
* 🌍 **Умная гео-сортировка:** Программа парсит названия стран из ключей и аккуратно группирует рабочие серверы по регионам.
* 🌐 **Интерактивный HTML-дашборд:** Автоматическая генерация стильного веб-отчета на вашем Рабочем столе с цветовой индикацией и кнопками быстрого копирования.
* 🎵 **Звуковое уведомление:** Сигнал об успешном завершении проверки[cite: 2].
* 🔄 **Масштабная агрегация:** Автоматический сбор конфигураций из проверенных источников (Black, White, SNI, CIDR, Reality и Extra листы)[cite: 2].
